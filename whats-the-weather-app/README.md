# What's the Weather

Build a weather application that showcases your ability to create a production-ready front-end

## Setup

`npm install`
`npm run dev`

## Scripts

- `npm run dev` this will start the dev server
- `npm run build` this will type check and build for production
- `npm run lint` this will run ESLint and provide any lint errors
